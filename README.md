# 岗位 RAG · 实习/校招情报助手

基于真实招聘信息的**检索增强问答（RAG）** Web 应用，面向**大学生实习 / 校招 / 应届求职**场景。用自然语言提问，即从岗位库中检索相关 JD，并由大模型生成结构化、可落地的建议，且**每条回答都可溯源到真实岗位**。

> 示例提问：
> - 「无锡有哪些接受本科、薪资 15k 以上的 AI 岗？」
> - 「我是大数据专业本科、零基础，能投哪些起步岗？」
> - 「南京做 RAG / 大模型算法的实习有哪些公司？」

---

## 功能

- **自然语言问答**：基于检索到的真实岗位资料作答，支持城市 / 学历 / 薪资 / 技术方向等复合条件。
- **可溯源、防幻觉**：回答 grounding 在检索结果上，并展示来源岗位卡片（公司 / 岗位 / 城市 / 薪资 / 类型 / 标签）。
- **数据看板**：首页展示岗位总数、按类型（实习 / 校招 / 社招）、按城市的实时分布。
- **自助扩充数据**：界面「粘贴补充一条岗位」可把 JD 即时入库并立即可被检索；也可批量编辑 `jobs.json` 后点「重建索引」。
- **开箱即用**：首次启动若向量库为空，会自动用 `jobs.json` 构建索引，无需手动跑脚本。

## 技术栈

| 层 | 选型 |
|---|---|
| 后端 | Flask + Chroma 向量库（持久化） |
| 嵌入 | 硅基流动 `BAAI/bge-m3`（中文检索效果好） |
| 问答 | 硅基流动 `deepseek-ai/DeepSeek-V3` |
| 前端 | 单页 HTML（原生 JS，零构建） |
| 数据 | `jobs.json`（**137 条**可溯源的长三角真实岗位） |

## 目录结构

```
app.py            Flask 服务：/ 界面、/ask 问答、/jobs、/stats、/add、/rebuild
rag_core.py       共享核心：配置、客户端、嵌入、岗位文本化、索引构建（app/build_index 共用）
build_index.py    索引构建命令行入口（rag_core.build_collection 的封装）
index.html        交互界面（问答 + 数据看板 + 补充岗位 + 重建索引）
jobs.json         岗位数据（可被 /add 或手工扩充，重建索引生效）
knowledge.txt     早期单文档 RAG 示例（可忽略）
rag_minimal.py    最小化 RAG 模板（学习用）
```

## 本地运行

```bash
cd Desktop/RAG
pip install -r requirements.txt
cp .env.example .env          # 然后填入你的硅基流动 API key
python app.py                 # 启动，访问 http://localhost:5000
```

- 服务监听 `0.0.0.0:5000`，同一局域网内其他设备可用本机 IP 访问。
- **索引自动构建**：第一次启动、或 `chroma_db/` 为空时，`app.py` 会用 `jobs.json` 自动生成向量库（需联网调用嵌入 API）。之后直接复用，无需重跑。
- 若你手动往 `jobs.json` 增删了岗位，点界面上的「重建索引」按钮，或运行 `python build_index.py` 即可生效。

## 数据说明（重要）

- `jobs.json` 为 2026-08 期间在 **猎聘 / 实习僧 / 应届生求职网 / 智联 / 国聘 / 牛客 / 全职招聘网 / 各高校就业网** 等公开渠道检索到的**真实在招岗位**，覆盖无锡、苏州、南京、上海、常州、南通及下属区县。
- 每条记录含 `company / title / city / type / salary / edu / exp / requirements / tags / source / updated`，`source` 标注检索来源。
- **薪资、要求以检索时页面为准，并非实时在招**；实际投递请以各招聘平台最新信息为准。本项目聚焦「检索 + 问答」能力演示，不构成任何求职承诺。

### 当前数据规模

- 岗位总数：**137 条**
- 类型分布：实习 74 · 校招 44 · 社招 19
- 覆盖城市：无锡、苏州、南京、上海、常州、南通（含江阴 / 新吴 / 滨湖 / 工业园区 / 张家港 / 建邺 等区县）
- 技术方向标签示例：大模型、RAG、Agent、Python、机器学习、计算机视觉、前端、数据分析、BI、运筹优化、自动驾驶、数据开发 …

## API 速览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/` | 交互界面 |
| POST | `/ask` | body `{question}` → `{answer, sources}` |
| GET | `/jobs` | 当前库全部岗位与数量 |
| GET | `/stats` | 按城市 / 类型 / 标签的聚合统计 |
| POST | `/add` | 自助补充一条岗位（JD 入库） |
| POST | `/rebuild` | 用 `jobs.json` 重建向量索引 |
